# 홀덤 토너먼트 승률·액션 계산기 (근사)

6인 토너먼트(BB 앤티 1bb)에서 내 포지션·핸드·스택과 상대 액션을 입력하면
169개 핸드의 액션 빈도, EV, 승률, 팟 획득 확률을 보여주는 계산기예요.
**근사 계산**이며 GTO 솔버 결과가 아니에요.

- 파일 하나(`index.html`)로 동작, 서버 없음. 계산은 Web Worker에서 실행.
- **ICM(순위 점수)**: 남은 인원(최대 6명)의 순위 점수로 칩 가치를 환산. 기본 점수 1~6등 `8,5,3,2,1,0`.
- **내시 균형 (푸시/폴드)**: 유효 스택 20bb 이하, 앞사람 전부 폴드(첫 액션) 또는 한 명 올인(콜/폴드) 상황은 ICM 순위 점수 기준 올인/폴드 내시 균형을 직접 계산 (콜러 1명 모델).
- **프리플랍 차트 (자체 솔버)**: 6인·20bb 초과 프리플랍(오픈 / 오픈 대응 / 3벳·4벳 대응)은 `tools/preflop_solver.js`로 미리 계산한 차트(25/40/60/100bb, 사이는 보간)를 사용. 상대 프리플랍 레인지 추정에도 사용. 단일 대응자·실현계수 모델, 칩EV.
  - 다시 만들기: `node tools/preflop_solver.js tools/charts.json 2000` 후 `index.html`의 `d-charts` 블록 교체
- **헤즈업 CFR 솔버 (턴·리버)**: 2명만 남은 턴·리버는 정해진 베팅 사이즈(리버 50·100%+올인, 레이즈 1회 / 턴 66%+올인 → 리버 75%+올인) 안에서 DCFR로 균형을 계산 (최대 약 8초, 균형 오차 표시, 칩EV 기준). 플랍은 계산하지 않음.
- **프리플랍 승률표**: 169×169 핸드 클래스 승률을 미리 계산해 내장 (쌍당 50,000회 몬테카를로).
- **PWA**: 안드로이드 크롬에서 열고 "홈 화면에 추가"하면 앱처럼 설치되고 오프라인에서도 동작.

## 폰에 설치 (GitHub Pages)

1. 이 저장소 → Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
2. 1~2분 뒤 `https://huskey38.github.io/POKERTEST/` 접속
3. 안드로이드 크롬 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

수정 후 배포할 때는 `sw.js`의 `VERSION`을 올려야 폰에 새 버전이 반영돼요.

|---|---|
